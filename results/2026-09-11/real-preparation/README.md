# Real data and source preparation

These are resource and runtime preflights, not VQA/caption benchmark scores.
P1 optimization results are reported separately after implementation review.

The public assets now cover four subjects, 120,000 single trials and 37,000
unique images. All 37,000 images join to NSD-VQA (807,728 automatically generated
questions) and COCO (185,093 caption references). The shared 1,000 images are
reserved for test across all subjects; remaining image identities use the
recorded deterministic train/validation split. The manifest validator found no
cross-split image leakage. Public upstream renormalized beta preprocessing is
recorded explicitly; it was not re-estimated here.

The real gradient preflight uses one exact-image KL and performs no optimizer
step. It verifies nonzero finite projector and LoRA gradients with a frozen
language-model base and frozen teacher projector. It is not NPP/P1 performance.
The BrainX probe strictly loads all 90 checkpoint tensors and runs real inputs
for subjects 01/02/05/07. This validates an UMBRAE cross-subject route, distinct
from the released subject01 VINDEX BrainXS model.

`baseline_sources.md` pins official DAPD/VAD implementations and identifies the
necessary NSD adaptations. CREDIT author code and a complete BrainJanus release
remain unverified; neither is silently replaced by a differently named method.
`calibration_sources.md` specifies a newly fitted Gaussian encoding likelihood,
not a publicly released VINDEX calibration file.

With the pinned public data downloaded under an asset directory, reproduce
the full manifest and annotation joins using:

```bash
PYTHONPATH=src python3 scripts/prepare_full_nsd.py --assets /path/to/brain-assets
PYTHONPATH=src python3 scripts/prepare_nsd_annotations.py --assets /path/to/brain-assets
PYTHONPATH=src python3 scripts/prepare_p1_manifest.py --assets /path/to/brain-assets --cohort results/2026-09-11/real-preparation/p1_cohort.json
```

The asset layout is the one recorded in the provenance files: NSD shards under
`nsd-inspection/webdataset_avg_new`, beta/behavior files under
`mindeyev2-inspection`, NSD-VQA parquet under `nsd-vqa`, and official COCO caption
JSON files under `coco`. Large tensors, images, weights and annotations stay
outside git. Their preparation outputs and checksums document the local runs.
The six annotation output files were regenerated byte-for-byte by the versioned
preparation script. Absolute paths in the historical manifest hash reflect this
machine; a different asset root changes that manifest hash.

The historical 46-trial P1 cohort was also reconstructed with the exact original
manifest hash. Three of its trials fall in the subsequently declared full-data
validation split. P1 is a separate development shape smoke: its weights and
small calibration artifacts must not initialize or calibrate full benchmark
evaluation. Full runs start from the pinned base and fit their training split.

The user-approved evaluation policy is exploratory, with no fixed performance
threshold stopping subsequent phases. Report measured positive and negative
changes honestly and retain control comparisons for interpreting neural use.
